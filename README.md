# GW Medidas 6.5.2 — Envio completo para o GW Assistente

- Medição local pode criar automaticamente cliente (se não existir) + orçamento no GW Assistente.
- O novo orçamento nasce como Rascunho e recebe o levantamento técnico.
- Se o cliente já existir pelo mesmo nome, o cadastro é reutilizado para evitar duplicidade.
- Continua possível vincular a orçamento/projeto existente.
- Orçamentos vindos do GW enviam levantamento ao orçamento.
- Projetos aprovados vindos do GW atualizam o levantamento do projeto.
- Fotos ainda não são transferidas como arquivo nesta etapa; a quantidade é registrada.
